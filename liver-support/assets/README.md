# assets — 切り抜き素材

ライバーごとにディレクトリを切って、配信の切り抜き（mp4）を置く。

```
assets/
  hina/001.mp4
  hina/002.mp4
  ren/001.mp4
```

動画ファイル自体は git で管理しない（`.gitignore` 済み）。
共有ストレージに置き、`config/livers.json` からは相対パスで参照する。

置く前に確認すること:

- 本人が切り抜きの利用に同意しているか（同意していない素材は登録しない）
- コラボ相手・リスナーの声・BGM など第三者の権利が混ざっていないか
- 配信プラットフォーム側の切り抜き利用規約に反していないか

登録の仕方は [../docs/workflow.md](../docs/workflow.md) を参照。

# フック設計プレイブック

冒頭2〜3秒で離脱するかどうかが決まる以上、投稿の成否のほとんどはフックで決まる。
このワークフローが自動化するのは「フックを素材に載せて投稿する」ところまでで、
**どの型が刺さるかの判断は人間が持つ**。ここはその判断のための資料。

## 型の一覧

`config/hooks.ja.json` に入っている型。ジャンルとの相性は目安。

| 型 | 効くもの | 例 | 相性 |
| --- | --- | --- | --- |
| 共感 | 視聴者が自分ごと化する | 「雑談配信でこれ、あるあるすぎる」 | 雑談・ASMR |
| 意外性 | 続きが気になる | 「この後まさかの展開になります」 | ゲーム・企画 |
| 損失回避 | 見逃したくない | 「消える前に見て」 | 全般（多用注意） |
| 認知獲得 | 誰なのかを伝える | 「毎晩21時配信してるひなです」 | 新人・立ち上げ期 |
| 問いかけ | コメントを誘発する | 「この対応、正解だったと思う？」 | 雑談・相談系 |
| 実演 | 中身を即見せる | 「残り1秒の逆転を30秒で見せます」 | ゲーム・歌 |

ライバーごとに `hookTypes` で使う型を絞る。
キャラに合わない型を混ぜると、数字以前に本人が嫌がる。ここは必ず本人と決める。

## 型を足す

`config/hooks.ja.json` に1行足すだけ。

```json
{ "id": "toi-03", "type": "問いかけ", "template": "{topic}のとき、みんなどうしてる？", "requires": ["topic"] }
```

- `{name}` ライバー名 / `{genre}` ジャンル / `{topic}` 切り抜きの中身 / `{tag}` タグ / `{time}` 配信時間帯 / `{cta}`
- `requires` に挙げた変数が空の素材では、その型は選ばれない
- 1文は**12文字 × 2行**に収まる長さで書く（テロップの折り返し既定）

## AI にフック文を書かせる場合

型ごと丸投げするのではなく、**型と変数を枠として渡す**。
出力がそのまま `hooks.ja.json` の1エントリになる形にしておくと、人のレビューが入れやすい。

```
あなたはTikTokの縦動画のフック文を書く。以下の制約を守り、候補を5つ出す。

# 制約
- 12文字以内 × 最大2行（合計24文字以内）
- 型: 意外性（続きが気になるが、内容を明かさない）
- 誇張・断定・煽りは禁止。実際の切り抜き内容を超える約束をしない
- 出力は JSON 配列: [{"id":"igai-04","type":"意外性","template":"..."}]

# 素材
ライバー: れん（ゲーム配信 / 平日22時）
切り抜きの中身: 残り1秒からの逆転
タグ: ゲーム実況
```

**釣りフックは禁止**。中身と食い違うフックは3秒維持率だけ上げて、
プロフィール遷移とフォローを確実に落とす。`report` を見れば1週間で分かる。

## 切り口テストの設計

`lsw plan --experiment` は、同じ素材に**型の違う**フックを当てて出し分ける。
比較の単位を言い回しではなく型にするのは、同じ型の中の言い換えでは差が出にくいため。

1回のテストで変えるのは次の2つだけにする。

| 変えるもの | 変えない方がよいもの |
| --- | --- |
| フックの型（意外性 → 問いかけ など） | 投稿時刻 |
| 見せどころ（`segments`） | ハッシュタグ |
| | CTA の文言 |

3つ以上を同時に変えると、勝った理由が分からなくなる。
「勝ったが理由が説明できない」状態は、次の1本に活かせないので勝っていないのと同じ。

判定は各切り口が**2本・1000再生**に届いてから（`experiment.minPostsPerVariant` /
`minViewsPerVariant`）。1回のラウンドでは足りないので、同じ素材を後日また回す。
2ラウンド目は前回と同じ切り口が優先して当たり、データが積み上がる。

負けた切り口はその素材で捨てるだけで、型そのものを捨てない。
素材との相性で負けることがあるので、別の素材では試す価値が残っている。

## 改善サイクル

1. `lsw report` でフック型別の3秒維持率を見る
2. 下位の型は `hookTypes` から外すか、文言を書き換える
3. 上位の型は言い回し違いを2〜3本足して幅を持たせる
4. 型を増やしすぎたら、本数の少ない型を削る（1型あたり最低5投稿は回さないと判断できない）

同じ型ばかり回すと視聴者に「またこれか」と学習されるので、
`hookCooldownDays`（既定7日）は縮めない。

## AI生成素材のフック

AI生成素材レーン（グッズカット・背景・b-roll）にも同じフック型を当てる。
違うのは制約が1つ増えることだけ。

- **中身を超える約束をしない**。実写以上にここを守る必要がある。
  生成映像は「それっぽい画」がいくらでも作れるので、
  フックだけ強くして中身が伴わない投稿が作りやすい
- キャプションには開示が自動で入る。フック文でそれを打ち消す表現をしない
  （「これ、本物です」のような文言をAI素材に当てない）

プロンプト側の型は `config/ai-prompts.ja.json`。フック型とは別物で、
**フック＝視聴者に見せる言葉**、**プロンプト＝素材を作るための指示**。混ぜない。

## テロップ

- フック文とテロップは別物にできる（素材の `telop`）。フック＝引き、テロップ＝中身の補足
- 折り返しは12文字（`video.telopPerLine`）。日本語は単語境界が無いので文字数で折る
- 下から320px（`telopMarginBottom`）。TikTok の UI と被らせない

# 取材記事・掲載前共有

最初に `.claude/work-style.md` を読む。

## 入力
- 対象（企業名、プレスリリースURL、イベントページなど）
- 媒体。指定がなければテーマから推定し、推定した旨を伝える。

## 手順
1. **調査**: 公式サイト・プレスリリース・公開資料をWebで集める。出典URLを台帳（事実／出典／確認日）にまとめる。
2. **重複確認**: Gmailで対象名を検索し、過去に送った記事・やりとりがあれば内容を踏まえる（同じ相手に二重送付しない）。
3. **記事草案**: 次の構成で書く。
   - タイトル（読者が得る示唆が分かる形）
   - リード（3文以内）
   - 本文: 「公式発表の内容」と「編集部の考察」を見出しで分ける
   - 読者（経営者・事業責任者）への示唆
   - 出典一覧、要確認事項
4. **Word化**: `anthropic-skills:docx` で `<媒体略号>-<対象略号>_<媒体>_入稿原稿_v1_<YYYYMMDD>.docx` を作る。
5. **メール下書き**: 広報窓口アドレスを公式サイトから探し、Gmailの下書きを作ってWordを添付する。見つからなければ宛先を空にして、問い合わせフォームのURLを報告する。

## メール雛形
件名: `【<媒体名>】<相手名>様の取り組みを紹介する原稿のご共有`

```
<相手名>
ご担当者様

お世話になっております。
「<媒体名>」<肩書>の<氏名>と申します。

<媒体紹介 1〜2文>
<媒体URL>

<相手の取り組みへの敬意 1文>

このたび、<きっかけ>を拝見し、公開情報をもとに紹介記事を執筆しました。<記事の視点 1〜2文>

掲載前の原稿をWordで添付いたします。公式発表の内容と当媒体の編集上の考察は分けて記載しています。事実関係に誤記がお目に留まりましたら、該当箇所だけお知らせいただけますと幸いです。ご返信はどうぞお気遣いなく。

<締めの感謝 1文>
よろしくお願いいたします。

<媒体名> <肩書>
<氏名>
<媒体URL>
```

## 出力
記事タイトル、下書きのリンク、要確認事項を報告する。送信はしない。

# 今日・今週のブリーフ

最初に `.claude/work-style.md` を読む。

## 集めるもの
1. **予定**（Googleカレンダー、指定がなければ今日から7日）
   - 打ち合わせ・取材: 相手の会社と、Gmail/Slackでの直近のやりとりを1〜2行で添える
   - 定例会議（毎週・隔週で繰り返す予定）には、前回の会議以降の関連メール・前回の宿題・関連資料（Drive）をまとめた準備メモを付ける
   - 期限モノは `deadline-watch` と同じ方法で拾い、🔴🟠で表示する
   - 交流会・セミナーは `event-triage` と同じ方法で重なりと重複だけ指摘する
2. **返事待ち**: 直近14日に自分が送った原稿共有・取材相談のうち返信がないもの
3. **返事すべき**: `inbox-triage` の A 区分に当たるもの（件数とリンクのみ。下書きは頼まれたら作る）
4. **制作中**: Driveで直近7日に更新したファイルをファイル名の接頭辞（系列）ごとにまとめ、最新番号と件数を示す
5. **掲載の進み具合**: `publish-tracker` の「要返信」だけ
6. **Slack**: 自分宛てのメンション・DMで未返信のもの、「了解」と返したまま未納品のもの

## 出力
次の順で短く:
1. 今日の予定と準備メモ
2. 今週の要注意（締切、重なり、返事待ち）
3. 制作中のシリーズと次の番号
4. 提案（どのスキルで何を片付けられるか）

何も送信・登録しない。

# 活動報告記事

最初に `.claude/work-style.md` を読む。

## 入力
- 動画URL（YouTube）または文字起こし、日付、対象の政治家名（指定がなければSlackの依頼から判断）

## 手順
1. **素材集め**: 動画の字幕・概要欄を取得する（取得できなければ文字起こしの貼り付けを頼む）。Slackの関連チャンネルで直近のやりとり・方針を検索し、決まっている表記（肩書など）に従う。
2. **既存記事との重複確認**: 公開済みの記事と内容が重なる場合は、「新規記事」か「既存記事の補足・差し替え候補」かを分けて提案する。
3. **草案**: 本人の一人称による活動報告の形で書く。
   - タイトル、本文（話した場所・相手・論点・本人の思い）、振り返り
   - 掲載日は「開催翌日の日付」を提案する
   - 肩書・所属・数字は公開情報で裏付けを取り、取れないものは要確認として列挙
   - 他候補への批判や断定的な表現は避ける
4. **表記チェック**: 過去の修正指示から「表記ルール表」を毎回作り直して当てる。
   - Slackの関連チャンネル・DMで、自分の草案への返信のうち「〜にしてください」「〜は避けて」「〜を削除」「出典」「肩書」を含むものを直近60日分集める
   - ルール（主語、使わない語、時期によって避ける表現、数字の出典、肩書の書き方、画像の扱いなど）を表にし、草案に当てて違反箇所を直す
   - ルール表は**リポジトリに保存しない**（公開リポジトリのため）。報告の中で示すだけにする
5. **Word化**: `anthropic-skills:docx` で保存する。
6. **Slack下書き**: 共有文を `slack_send_message_draft` で下書きにする。

## Slack共有文の雛形
```
<対象動画>の記事草案を、これまでと同じ本人の活動報告の形でまとめました。
Wordを添付しますので、ご確認・調整のうえご活用ください。
<新規／差し替え候補の区別、要確認事項があれば箇条書き>
よろしくお願いいたします！
```

## 未納品の確認（頼まれたとき、または草案作成のついでに）
Slackで自分が「了解」「かしこまりました」と返した依頼のうち、その後にファイルやURLを出していないものを一覧にする。

## 出力
記事タイトル、Wordの保存先、Slack下書きの場所、要確認事項。投稿はしない。

# イベント申込の仕分け

最初に `.claude/work-style.md` を読む。カレンダーは**変更しない**（提案だけ）。

## 手順
1. 対象期間（既定: 今日から14日）の予定を取得する。
2. 予定を分類する: 社内定例・会議／打ち合わせ・取材・面接／外部イベント／締切／私用。
3. 外部イベントについて:
   - 同じ時間帯に重なる予定を組にする（会議や打ち合わせと重なるものは原則「行かない」案）
   - 件名が同じか似ている予定（Gmail自動追加と手入力、表記ゆれ）を「重複」として挙げる
   - 説明欄や Gmail の申込メール（Peatix、luma、connpass など）からキャンセル期限・費用・会場を拾う
   - 関連度を判断する: 自社の媒体・出版・地域共創・AI活用・取引先・取材候補につながるかを、直近の Gmail と Drive の制作物から推定する
4. 「行く／迷う／行かない」の案と理由を一行で付ける。

## 出力
1. 重なり一覧（日時・候補・案）
2. 重複予定の一覧（統合してよいもの）
3. キャンセル期限が近いもの
4. 行く予定のイベントで「会いたい人・聞きたいこと」のメモ（取材候補につながるものだけ）

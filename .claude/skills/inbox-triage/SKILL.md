# 受信トレイの仕分けと返信下書き

最初に `.claude/work-style.md` を読む。

## 対象
既定は直近3日の `in:inbox`。期間指定があれば従う。

## 分類
| 区分 | 例 | 対応 |
|---|---|---|
| A 要返信 | 広報からの記事確認・修正依頼、取材・掲載の相談、打ち合わせのお礼や日程、知人からの連絡 | 返信の下書きを作る |
| B 期限あり | 請求書・振替、イベント申込締切、セキュリティ／情報漏洩の通知 | 期限と必要な行動を一覧化 |
| C 問い合わせフォーム経由の営業 | FC加盟・広告・ツールの売り込み | 件数と一行要約だけ。返信しない |
| D 媒体ネタ | 掲載・紹介の依頼、Googleアラート、業界ニュース | 記事化できそうなものを候補として挙げる |
| E その他 | ニュースレター、SNS通知、ログイン通知 | 件数のみ |

## 手順
1. 期間内のスレッドを検索し、必要なものは `get_thread` で全文を読む（検索結果のプレビューだけで判断しない）。
2. A は相手の依頼に答える返信を `create_draft`（`replyToMessageId` 付き）で作る。判断が要る点（日程、金額、修正を受けるか）は本文に【要判断】と書いて残す。
3. D で記事にできそうなものは `article-pitch` で扱える形（対象名・きっかけ・URL）で並べる。

## 出力
A〜E の件数、A の下書き一覧（リンク付き）、B の期限一覧、D の記事候補。何も送信・削除・ラベル変更しない。

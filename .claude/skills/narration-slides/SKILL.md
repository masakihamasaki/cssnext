# ナレーションスライド（動画化）

最初に `.claude/work-style.md` を読む。

## 入力
- 元原稿（Drive上のファイル、記事URL、テキスト）
- シリーズ略号と開始番号。分からなければDriveの最近のファイル名から次の番号を推定して確認する。

## 変換ルール（ツールが自動で行う。手で直すときの参考）
- **1スライド1文**、目安40〜60字。番号は `01`, `02`…
- 構成は「問いかけ → 答え」の対を基本にする（例: 「〜で困っていませんか。」→「〜します。」）。見出しスライドは短い名詞句。
- **読み上げ表記に直す**（Vidsの音声合成で誤読させないため）:
  - 年・数字は読みの漢字に: 2027年 → 二千二十七年、54市町村 → 五十四市町村、1873年 → 千八百七十三年
  - 英字略語はカタカナに: AI → エーアイ、DX → ディーエックス、M&A → エムアンドエー、PoC → ピーオーシー、HR → エイチアール、WordPress → ワードプレス、note → ノート
  - 誤読しやすい語はひらがなに: 事業承継 → 事業しょうけい
- 1ファイル25〜35枚で区切り、超える分は次の番号のファイルにする。
- **全系列で同じ読み替えを使う。** Googleスライドから作る系列（3枚1組のテンプレートなど）でも、日付・数字・英字は必ず読みに直す。

## 系列違い（同じ原稿から複数系列を作るとき）
- 原稿を系列ごとに手で切り直さない。**基本系列**を1つ作り、他の系列は「差し込む定型文」と「差し込む間隔」（例: 3枚ごと）のルールで自動生成する。
- ルールは本人に確認し、決まったら報告に書いておく。

## 命名
- `<系列>_<番号3桁>_v<版>_<YYYYMMDD>.pptx`（例: `ABC_011_v1_20261010.pptx`）。枝番が必要なら番号の後に `a` `b`。
- 版違いを別名（最終・確定・FIX・PATCH など）で増やさない。
- 事実と考察を混ぜない。保証・断定表現は使わない。

## 手順
1. 元原稿を Markdown / テキスト / HTML / docx で手元に用意する（Drive のファイルは読み込んで保存する）。見出しや箇条書きはそのままでよい。
2. **変換ツールで作る**（手で書き写さない）:
   ```
   python3 work-tools/content/narration.py <元原稿> --series <系列> --out-dir <出力先> \
     [--variant <系列2>:<間隔>:<差し込む定型文>] --dict <readings_private.json を保存したパス>
   ```
   - 文の分割、読み替え、長文の分割、1ファイル30枚での区切り、命名、連番の続き、系列違いの生成までツールが行う
   - 人名・地名・社名・シリーズ固有の読みは、Drive の `readings_private.json` に書く（リポジトリには入れない）
3. ツールが出す報告（`<系列>_report_<日付>.json`）を確認する:
   - `unconverted_words`: 読みに直せなかった英単語 → 読みを決めて辞書に足し、作り直す
   - `too_long`: 分割できなかった長文 → 元原稿を直して作り直す
4. Google Driveにアップロードする（Vidsへの取り込みは本人が行う）。
5. 頼まれたら、Driveの整理候補（空の「無題の動画」、同名の重複Vids、拡張子 `.pptx` が残ったVidsタイトル）を一覧にする。削除はしない。
6. 制作管理シートがあれば、作ったファイルの行の状態を報告用に示す（書き込みは頼まれたときだけ）。

## 出力
ファイル名と枚数、Driveのリンク、読み替え一覧。

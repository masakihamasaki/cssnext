# 個別案内メールの一括下書き

最初に `.claude/work-style.md` を読む。

## 入力
- イベント情報（名称、日時、場所、内容、申込方法・URL）
- 宛先リスト（名前・会社・メール。スプレッドシート、貼り付け、または過去の送信履歴から）

## 手順
1. 宛先ごとにGmailで過去のやりとりを検索し、関係が分かる一言（前回会った場、前回の話題）を拾う。見つからなければ一言は入れない（作らない）。
2. 件名は `<姓>様｜<日付>（<曜日>）<場所>／<イベント名>のご案内` の形。
3. 本文は共通部分＋相手ごとの一言＋申込方法。BCCの一斉送信にはしない。
4. 1件ずつ `create_draft` で下書きを作る。
5. 宛先・一言の根拠を表にして報告する。

## 宛先の検証（下書きを作る前に必ず）
- Gmail で `from:mailer-daemon` と「Undelivered」「配信できませんでした」を検索し、過去に不達になったアドレスを宛先から外して「不達履歴あり」として一覧に出す。
- 名刺交換から年数が経っている相手は、公開情報で現在の所属を確かめ、変わっていれば「要確認」とする。
- 相手の最近の記事・発表・資金調達などを調べて一言にする場合は、出典URLを報告表に残す。

## 注意
- 宛先が30件を超えるときは、先に5件だけ作って本人に文面を確認してもらう。
- メールアドレスの推測はしない。分からない人は「宛先不明」として一覧に残す。

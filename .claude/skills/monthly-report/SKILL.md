# 月次レポートの下書き

最初に `.claude/work-style.md` を読む。

## 手順
1. **定義を読む**: カレンダーで「月次レポート」「業務報告」を含む予定を探し、説明欄の指標の定義を読む。Drive で前月のレポート（`月次レポート` `業務報告書` を含むファイル）を探し、構成と書き方を合わせる。
2. **材料を集める**（対象月の1日〜末日）:
   - カレンダー: その取引先に関する会議・商談・取材・イベント
   - Gmail: その取引先や関連企業とのやりとり、商談化・受注・相談の兆し
   - Drive / スプレッドシート: 営業リスト・管理ボードの更新、作った資料
3. **指標ごとに数字を出す**。数えた根拠（どの予定・メール・シートの何行か）を脚注に残す。数えられない指標は「—（要確認：理由）」と書く。数字を推測で埋めない。
4. **構成**: 今月の要点（3行）→ 指標の表（今月・前月・差）→ 主な出来事 → 課題 → 来月の予定。
5. Docs に `<取引先>_<レポート名>_<YYYY年M月度>_ドラフト` として保存する。

## 出力
Docs のリンク、要確認の指標一覧。提出は本人が行う。

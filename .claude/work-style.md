# 仕事スタイル（全スキル共通ルール）

全スキルはこのファイルを最初に読むこと。

> このファイルとスキルは公開される可能性がある。取引先名、人名、金額、メールアドレス、表記ルールなどの具体的な情報は**ここに書かない**。必要な情報は実行のたびに Gmail・カレンダー・Slack・Drive から読み取り、報告の中だけで使う。

## 非公開設定（最初に読む）
Google Drive の `work-automation-private` フォルダに、公開リポジトリに書けない設定がある。`search_files` で題名から探して読む（ID はリポジトリに書かない）。

| ファイル | 中身 | 使うスキル |
|---|---|---|
| `work-automation 非公開設定`（Docs） | 1 媒体と名乗り・送信元／2 選挙記事の表記ルール／3 期限・定例／4 台帳・仕様のありか／5 公開禁止語 | 全スキル |
| `readings_private.json` | 人名・地名・固有名の読み | narration-slides（`--dict`） |
| `manuscript_spec.json` | 執筆仕様の機械チェック用設定 | manuscript-check（`--spec`） |

- JSON は `download_file_content` で一時フォルダ（スクラッチパッド）に保存してから使う。リポジトリ内には保存しない。
- セッションの最初に、`~/.config/work-automation/blocklist.txt` がなければ、非公開設定の「5 公開禁止語」を1行1語で書き出す（コミット前の自動チェックが使う）。
- 新しいルール・読み・期限が分かったら、本人に確認したうえで非公開設定に追記する。

## 基本ルール
- **送信・投稿・公開・削除はしない。** Gmailは下書き、Slackは下書き（`slack_send_message_draft`）、ファイルは新規作成まで。送るのは本人。
- 事実と編集上の考察を分ける。確認できない主張は言い切らない。出典URLを残す。
- 権利・同意が未確認の素材（写真、証言、企業資料）は本文に入れず「要確認」として列挙する。
- 成果（掲載・視聴数・売上）を約束する表現は使わない。
- 取得した個人情報・取引情報をリポジトリのファイルに書き込まない。

## 名乗り・媒体・送信元アドレス
非公開設定の「1 媒体と名乗り」に従う。載っていない相手・媒体は、同じ相手・同じ媒体へ過去に送った Gmail の送信済みメールを探し、そこで使っている名乗り・肩書・署名・媒体URL・送信元アドレスに合わせる。見つからなければ本人に確認する。

## 文体
- 丁寧で控えめ。相手の取り組みへの敬意を最初に一文入れる。
- 「ご返信はどうぞお気遣いなく」「誤記がお目に留まりましたら、該当箇所だけお知らせください」のように相手の負担を下げる一文を入れる。
- 一文は短く。カタカナ語を多用しない。

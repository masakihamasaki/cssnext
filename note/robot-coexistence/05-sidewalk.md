# 歩道を分け合う ― 配送ロボットと自動運転

歩道は、思っているよりずっと複雑な場所です。

歩く人、走る人、ベビーカー、車椅子、白杖の人、自転車、立ち話をする人、看板、電柱、自販機、放置自転車。
そこに小さな配送ロボットが加わりました。

「配送ロボットが歩道を走る」と聞いたときの反応は、たいてい二つに割れます。
「便利そう」と「邪魔じゃないか」。

そして、この二つは対立していません。**便利であり、かつ邪魔になり得る**。共生の問題は、いつもこの形をしています。

## 歩道は誰のものか、という古い問い

新しいのはロボットではなく、問いのほうが古いのだと思います。
歩道は自転車で揉め、電動キックボードで揉め、看板や路上駐車で揉めてきました。歩道はずっと、**限られた幅を誰にどう配分するか**の争いの場でした。

ロボットは、この争いに新しい参加者として入ってきます。しかも特殊な性質を持っています。

- 疲れない(長時間そこにいる)
- 台数を増やせる(需要に応じて指数的に増える)
- 交渉できない(道を譲るかどうかの「目配せ」ができない)

最後の一つが厄介です。
人間同士は、すれ違うときに視線で微調整しています。どちらが避けるかを、言葉なしで一瞬で決めている。ロボットはこの交渉に参加できないので、**人間の側が全部避けることになります**。

一台なら気になりません。十台になると、歩道の性質が変わります。

## 「誰が譲るか」を設計しないと、弱い人が譲る

ここで重要なのは、負担が均等に配分されないことです。

急いでいる健常者は、さっと避けられます。
杖をついている人、車椅子の人、視覚障害のある人、子どもを連れた人は、そう簡単ではありません。

**避けるコストは、動きにくい人ほど高い。**

つまり「ロボットは人を優先します」という仕様は、それだけでは足りません。優先の中身が問題です。

- ロボットは十分手前で減速するか
- 進路をどう変えるか予測できるか(急にどちらかへ寄らないか)
- 音や光で存在と意図を伝えているか
- 視覚障害のある人に、存在が分かるか
- 詰まったとき、通せんぼしたまま止まらないか

最後の「止まり方」がとくに大事だと思っています。
安全のために止まる、は正しい。しかし**狭い場所で止まったロボットは、障害物そのもの**です。安全設計としては正しく、共生設計としては失敗している。

## 自動運転車と同じ問題が、縮尺を変えて出てくる

車道側の自動運転でも、構造は同じです。

- 完全にルールを守る車は、割り込まれ続けて前に進めない
- 人間のドライバーは、アイコンタクトと微妙な前進で交渉している
- 交渉できない車は、周囲の人間に交渉の負担を押し付ける

「交通ルールを完璧に守れば安全」ではなく、**交通は暗黙の交渉で回っている**。この事実に、自動化は正面からぶつかります。

だからこの分野の課題は、認識性能よりも、**意図をどう表現するか**に移りつつあるのだと理解しています。
「私はあなたを見ています」「私は止まります」を、人間に伝わる形で外に出す。ウィンカーが百年前に解いた問題を、もう一度解き直している。

## 誰が苦情を受け取るのか

もうひとつ、制度側で抜けやすいのが受け皿です。

歩道でロボットに困ったとき、人はどこに言えばいいのでしょうか。

- 事業者のサポート窓口(その場では分からない)
- 自治体(管轄が曖昧)
- 警察(事故でなければ動きにくい)

結果として、多くの「困った」はどこにも記録されません。
記録されない不満は、統計上「問題なし」になり、ある日まとめて反発として噴き出します。

私は、街に出るロボットには**車体に大きく問い合わせ先が書いてある**べきだと思っています。原始的ですが、これは「誰が責任者か分かる」という共生の基本条件です。

## 私の仮の結論

- 歩道の問題は「幅の配分」であり、ロボットは新しい参加者にすぎない
- 交渉できない参加者は、交渉の負担を周囲に押し付ける
- 負担は動きにくい人に偏る。だから優先の中身を具体的に決める必要がある
- 止まり方まで含めて設計する(止まったロボットは障害物)
- 苦情の受け皿を最初に作る。記録されない不満は蓄積する

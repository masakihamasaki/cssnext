# 検索窓の前で、立ち止まる子ども

検索窓は、世界でいちばん親切な入口です。

何を入れても、何かが返ってきます。分からなくても、とりあえず打てば進める。

だから、立ち止まる子どもは珍しい。

## 立ち止まるのは、能力が低いからではない

検索窓の前で手が止まる子を見ると、大人はつい助けたくなります。

- 「〇〇って入れてごらん」
- 「こう聞けば出てくるよ」

親切です。そして、その瞬間に、**いちばん大事な時間が終わります。**

立ち止まっているあいだ、その子の中で起きていることは、たぶんこうです。

- 自分が知りたいのは、正確には何だろう
- どう言えば伝わるだろう
- そもそも、これは調べれば分かることなんだろうか

**これは、検索の手前にある「問いを作る」作業です。**

検索が上手な人は、これを一瞬でやっています。速すぎて、やっていることが見えない。だから、教えるのが難しい。

## 検索は、問いを「持っている人」の道具

検索エンジンも、AIも、問いに答える道具です。

裏を返すと、**問いを持っていない人には、何も返せません。**

「なんでもいいから面白いこと教えて」に返ってくるのは、誰にとっても面白そうなものです。その人のためのものではない。

だから、道具が賢くなるほど、価値の重心は移ります。

- 昔:答えを知っている人が強かった
- いま:**問いを持っている人が強い**

そして、問いは検索窓の中では作れません。**窓の手前で作られます。**

## 立ち止まりを、奪わないために

大人ができるいちばん簡単なことは、**待つこと**です。

これは次回のテーマでもありますが、ここでは具体的に三つだけ。

**一、キーワードを先に言わない**
「〇〇で調べたら?」は、その子の問いを、大人の問いに置き換えてしまいます。

**二、何を知りたいのか、言葉にしてもらう**
「何が気になってるの?」と聞く。答えられないなら、まだ問いになっていない。それが分かるだけで前進です。

**三、調べなくても分かることは、調べさせない**
外を見れば分かる天気を検索する必要はありません。**道具を使わない判断も、道具のリテラシーです。**

## 「検索してはいけない」ではありません

念のため書いておくと、検索させない教育を勧めているのではありません。逆です。

たくさん検索したほうがいい。

ただ、検索の**前後**に、一手ずつ足したい。

| | 足したい一手 |
|---|---|
| 前 | 「何が知りたい?」(問いを言葉にする) |
| 後 | 「で、どう思った?」(受け取ったものを判断する) |

前を飛ばすと、他人の問いに答えるだけになります。
後ろを飛ばすと、最初に出てきたものを事実として持ち帰ることになります。

この二手は、AIに何かを頼むときも、そのまま同じです。むしろAI相手のほうが、なめらかに答えが返ってくるぶん、飛ばしやすい。

## 「好きな検索」をしてみる

『こどもの未来 第1巻』の巻末には、**好きな検索をしてみる**というアクティビティが入っています。

このやり方が良いと思うのは、**正解のある調べ物ではない**ところです。

宿題の調べ物は、答えが決まっています。だから問いを作る練習になりません。

「好きなことを検索する」は、問いが自分から出てこないと成立しません。

- 何を打とうか、迷う
- 打ってみる
- 思っていたのと違うものが出てくる
- 打ち直す

この**打ち直し**が、いちばんの学びです。一発で欲しいものが出てこないという体験は、道具の限界と自分の言葉の両方を教えてくれます。

## 大人にも、同じ宿題があります

最後に、自分に返ってくる問いを置いておきます。

今日、あなたが検索した言葉のうち、**自分の問いから出てきたもの**は、何件ありましたか。

仕事で必要だから、誰かに聞かれたから、そういうものを引いていくと、案外少ないかもしれません。

立ち止まる時間は、子どもだけのものではないと思うのです。

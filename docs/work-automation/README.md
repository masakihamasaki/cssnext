# 仕事の自動化スキル

Claude Code でこのリポジトリを開き、下の「頼み方」のように話しかけると起動する。どれも **呼び出したときだけ動き、送信・投稿・削除はしない**（メールとSlackは下書きまで）。

## 仕組み
- **公開してよいもの**（手順・ツール）はこのリポジトリ、**非公開のもの**（名乗り、表記ルール、期限、読み辞書、執筆仕様）は Google Drive の `work-automation-private` フォルダ。スキルは最初に Drive の設定を読む。
- **漏えい防止**: `git commit` / `git push` の前に自動チェック（`.claude/hooks/privacy-guard.sh` → `work-tools/privacy_check.py`）が走り、メールアドレス・電話番号・金額・非公開リンク・Drive の ID・非公開リストの語があれば止める。プルリクエストでも同じチェックとテストが走る（`.github/workflows/work-tools.yml`）。
- **クラウドのセッション**: 開始時にツールの依存を入れ、非公開設定の場所を案内する（`.claude/hooks/work-session-start.sh`）。
- 送信・投稿・削除はしない。メールとSlackは下書き、ファイルは新規作成まで。

## 制作
| スキル | 頼み方の例 | 作るもの |
|---|---|---|
| `article-pitch` | 「〇〇社の取り組みで記事を書いて、広報に送る準備をして」 | 記事草案Word＋共有メールの下書き |
| `activity-report` | 「この動画を活動報告の記事にして」 | 記事草案Word（過去の修正指示を自動で反映）＋Slack下書き |
| `narration-slides` | 「この原稿を〇〇系列の次の番号で動画用スライドにして」 | 読み上げ用pptx（変換ツールで自動生成） |
| `manuscript-check` | 「第3巻を執筆仕様どおりかチェックして」 | 章ごとの問題一覧 |
| `content-pipeline` | 「このネタを記事・動画・SNSまで全部展開して」 | 元原稿1つから派生物一式＋管理シートの行 |

変換・点検は `work-tools/content/` のツールで行うので、毎回同じ結果になる。

## 連絡・進行
| スキル | 頼み方の例 | 作るもの |
|---|---|---|
| `inbox-triage` | 「受信箱を整理して」 | 仕分け結果＋返信下書き |
| `publish-tracker` | 「原稿の返事どうなってる？」 | 共有〜掲載の進行表＋要返信の下書き |
| `invite-batch` | 「このイベントの案内をこの人たちに」 | 不達アドレスを除いた個別メール下書き |

## 予定・期限・報告
| スキル | 頼み方の例 | 作るもの |
|---|---|---|
| `weekly-brief` | 「今週の段取り」「定例の準備」 | 予定・準備メモ・期限・返事待ち・制作状況 |
| `deadline-watch` | 「期限を確認」「今月の請求書」 | 請求・学会・申込などの期限一覧、請求書の下書き |
| `event-triage` | 「今週のイベントを整理して」 | 重なり・重複・行く/行かない案 |
| `monthly-report` | 「〇月の月次レポートの下書き」 | 指標の表と出来事をまとめたDocs |

共通ルール（名乗り、文体、事実と考察の分け方、送信しないこと）は `.claude/work-style.md`。
